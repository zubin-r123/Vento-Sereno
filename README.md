# Vento Sereno 🌬️

A fully functional multi-page React website built for a real boutique 
hotel business in Goa, India. Designed and developed as a freelance 
client project, built using Claude Code for accelerated development.

---

## Pages & Features

- **Homepage** — Hero section, brand intro, property highlights
- **Rooms** — Room listings with details and availability info
- **Menu** — Food and beverage offerings
- **Contact / Booking** — Functional enquiry and booking form for guests
- Responsive design across desktop and mobile
